AgentCore Workshop TelcoCare

Pulizia finale

Cancelli tutto quello che hai creato durante il workshop. Circa sette minuti, quasi tutti di attesa.

Le risorse del workshop costano poco quando non sono usate, ma alcune hanno un costo fisso o conservano dati. La pulizia le cancella tutte.

  1. Dalla cartella del progetto lancia lo script di pulizia.

    cd ~/agentcore-workshop/TelcoCare
bash ../scripts/pulizia.sh

    Lo script fa tre cose:

    • toglie tutte le risorse da agentcore.json con agentcore remove all --yes e pubblica il progetto vuoto con agentcore deploy --yes, così il CLI cancella lo stack AgentCore-TelcoCare-default;
    • cancella lo stack telcocare-crm della Lambda;
    • cancella i gruppi di log che restano dopo le risorse, cioè quelli che hanno TelcoCare o telcocare nel nome.
    Cosa dovresti vedere 
    removing stack AgentCore-TelcoCare-default
removed project 'TelcoCare' from target 'default'
...
stack telcocare-crm cancellato
cancellato /aws/bedrock-agentcore/runtimes/TelcoCare_default_agent-...-DEFAULT
...
Pulizia completata.
    Nelle nostre prove lo script ha impiegato circa 7 minuti, quasi tutti per cancellare lo stack AgentCore.

  2. Controlla che non sia rimasto nulla.

    aws cloudformation describe-stacks --query "Stacks[?contains(StackName,'TelcoCare') || contains(StackName,'telcocare')].StackName"
aws bedrock-agentcore-control list-agent-runtimes --query "agentRuntimes[?contains(agentRuntimeName,'TelcoCare')].agentRuntimeName"
aws bedrock-agentcore-control list-memories --query "memories[?contains(id,'TelcoCare')].[id,status]"
    Cosa dovresti vedere Tre liste vuote, []. Una Memory può restare per qualche minuto nello stato DELETING: è normale, sparisce da sola.
Cosa resta

Restano lo stack CDKToolkit, creato al primo deploy per preparare l'account a AWS CDK, e l'impostazione di CloudWatch Transaction Search. Non hanno a che fare solo con questo workshop, quindi lo script non li tocca. Restano anche i file sul tuo ambiente: il codice in app/, gli schemi e le regole.
