Lab 0 · L'ambiente

Controlli che Code Editor abbia tutto quello che serve. Dieci minuti.

Il tuo ambiente ha già AWS CLI, AgentCore CLI e Kiro CLI configurati. In questo lab non crei nulla: controlli le versioni, imposti la regione e fai una chiamata di prova al modello.

  1. Apri un terminale in Code Editor dal menu Terminal, New Terminal.

  2. Clona il repository del workshop. È privato: serve l'invito su GitHub che hai ricevuto per email, da accettare prima di questo passo.

    git clone https://github.com/mauriziopinto/agentcore-workshop.git ~/agentcore-workshop
cd ~/agentcore-workshop
ls

    Git ti chiede nome utente e password di GitHub. Come password GitHub non accetta quella dell'account: serve un personal access token. Se non ne hai uno, crealo da GitHub, in Settings, Developer settings, Personal access tokens, con il permesso di lettura sul repository.

    Cosa dovresti vedere Le cartelle docs (questo sito), risorse (i file da copiare nei lab) e scripts (piccoli strumenti di supporto).

  3. Imposta la regione per questo terminale e per quelli che aprirai dopo.

    export AWS_REGION=us-east-1
echo 'export AWS_REGION=us-east-1' >> ~/.bashrc

  4. Lancia lo script di verifica.

    bash scripts/verifica_ambiente.sh
    Cosa dovresti vedere Una riga [ok] per ogni controllo e alla fine Tutto pronto. La chiamata di prova al modello Claude Sonnet risponde pronto. 
      [ok]  credenziali AWS: arn:aws:sts::123456789012:assumed-role/...
  [ok]  regione us-east-1
  [ok]  Node.js v22...
  [ok]  uv 0.8...
  [ok]  Python 3.12...
  [ok]  AgentCore CLI 1.0.1
  [ok]  Kiro CLI 2...
  [ok]  il modello risponde: pronto

Tutto pronto. Puoi passare al Lab 1.
    Attenzione Se il modello risponde con un errore di accesso, il tuo account non ha ancora inviato il modulo che Anthropic richiede una volta sola prima di usare i modelli Claude su Amazon Bedrock. Chiama chi conduce il workshop.

  5. Dai un'occhiata ai comandi del CLI. Ogni comando ha il suo --help.

    agentcore --help

    Lanciato senza argomenti, agentcore apre un'interfaccia interattiva nel terminale. Nei lab usiamo sempre i comandi con le opzioni, così puoi copiarli così come sono.

Prova con Kiro

Kiro CLI è già configurato. Aprilo nella cartella del workshop e chiedigli di orientarti:

kiro-cli chat

Poi scrivi, per esempio: Leggi la cartella risorse e dimmi in una frase per ogni lab quali file contiene. Esci con /quit.
